# 🍦 Ice Cream Revenue Prediction

## Overview
A machine learning project that predicts ice cream revenue based on temperature using Simple Linear Regression.

## Objective
To find the relationship between temperature (°C) and ice cream sales revenue, and build a model to predict future revenue.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Scikit-learn

## Algorithm Used
Simple Linear Regression

## Dataset
Source: YBI Foundation
Features: Temperature (°C)
Target: Revenue (₹)

## Steps Performed
1. Imported libraries
2. Loaded and explored dataset
3. Visualized data (scatter plot)
4. Split data into train/test sets
5. Trained Linear Regression model
6. Evaluated model (R² score, MAE)
7. Visualized predictions

## Result
The model successfully predicts ice cream revenue based on temperature with good accuracy.
